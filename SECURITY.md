# Security Policy

## Supported Versions

Homeroom is a personal hobby project for local home-network use. Security updates are applied directly to the `master` branch.

| Version | Supported          |
| ------- | ------------------ |
| `master` | :white_check_mark: |
| < latest | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential exposure in Homeroom:

1. **Please do not open a public issue.**
2. Report the vulnerability privately via **[GitHub Private Vulnerability Reporting](https://github.com/zbergus/homeroom/security/advisories/new)**.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- Any suggested mitigations or fixes.

Reports will be reviewed as time permits. Thank you for helping keep open source software safe.
