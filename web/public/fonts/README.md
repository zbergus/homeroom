# Embedded Fonts

These fonts are bundled locally to ensure 100% deterministic rendering across all wall-mounted kiosks, tablets, and TV browsers without requiring internet connectivity or Google Fonts CDN access.

## Fonts Included:
1. **Barlow Condensed** (Weights: 600 SemiBold, 700 Bold, 800 ExtraBold)
   - Designer: Jeremy Tribby
   - License: SIL Open Font License, Version 1.1 (OFL)
   - Used for: Arena scores, team abbreviations, periods, jumbotron displays.

2. **JetBrains Mono** (Weights: 500 Medium, 700 Bold)
   - Designer: JetBrains
   - License: SIL Open Font License, Version 1.1 (OFL)
   - Used for: Tabular clocks, SOG, delays, hardware telemetry, LED matrix readouts.
